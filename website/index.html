Built for Unattended Reliability

A robust OS-level supervisor for autonomous agents

Native Windows System Tray

Windowless background launcher (`zsched-tray.exe`) with tray menu controls, desktop notifications, and optional user login startup without admin rights.

Windows Job Object Isolation

Workers are placed into Job Objects with `KILL_ON_JOB_CLOSE`. Canceling a task or stopping the daemon guarantees zero orphaned background processes.

Non-Drifting Random Windows

Sampled random times (e.g. `20h:30h`) are saved into durable state and survive daemon restarts, preventing random schedule drift on reboots.

Zero-Dependency Web Dashboard

Responsive web dashboard served directly from memory over authenticated loopback (`127.0.0.1`). Real-time run logs, countdowns, and controls.

AI Scheduling Assistant

Connect any OpenAI-compatible model (Ollama, vLLM, OpenAI) to natural-language schedule management, status queries, and log inspections via tool calls.

Side-Effect Free Recovery

Power losses mark active tasks `interrupted` rather than blindly duplicating runs, preventing catastrophic side effects in external tools or codebases.
